# جواب مشتری غفور

وب‌اپلیکیشن فارسی راست‌چین برای نگهداری پاسخ‌های آماده فروش آنلاین. فایل‌ها در ریشه پروژه هستند و پوشه `assets` نیاز نیست.

## انتشار در GitHub Pages
1. تمام فایل‌های ZIP را در ریشه یک repository آپلود کنید.
2. در GitHub وارد **Settings → Pages** شوید.
3. در بخش Build and deployment، گزینه **Deploy from a branch** را انتخاب کنید؛ شاخه `main` و پوشه `/(root)` را تعیین و ذخیره کنید.
4. سایت را با HTTPS باز کنید. برای نصب PWA، سایت را در Safari آیفون باز کنید، دکمه Share را بزنید و **Add to Home Screen** را انتخاب کنید.
5. برای آفلاین‌شدن، یک بار در حالی که اینترنت دارید سایت را باز کنید. تغییرات Service Worker ممکن است پس از بارگذاری مجدد فعال شوند.

## ذخیره‌سازی و پشتیبان
اطلاعات ابتدا در IndexedDB مرورگر ذخیره می‌شود و در صورت عدم دسترسی، از localStorage به‌عنوان جایگزین استفاده می‌شود. از بخش تنظیمات مرتب خروجی JSON بگیرید. پاک‌کردن داده‌های سایت در Safari می‌تواند اطلاعات محلی را حذف کند.

## عکس و آیکن
`profile.jpeg` عکس ارائه‌شده از صاحب برنامه است. فایل‌های `icon-180.png`, `icon-192.png`, `icon-512.png` در ریشه قرار دارند.

## محدودیت‌های مهم
- برنامه متن را کپی می‌کند؛ به گفتگوهای Facebook Messenger یا WhatsApp Business دسترسی مستقیم ندارد و پیام را خودکار ارسال نمی‌کند.
- اعلان و یادآور در مرورگرها و حالت نصب‌شده iOS محدودیت دارد.
- ادعای تحمل وزن ۵ کیلوگرم بر اساس مشخصات اعلام‌شده محصول است؛ پیش از استفاده واقعی، سازگاری و ایمنی نصب را بررسی کنید.
